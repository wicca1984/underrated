## Background
Today `src/engine/mod.rs` has an immutable, one-shot `Page { dom, styles, layout }` (spec: S-13). The browser renders one page and exits. To move toward interactive browsing (type → Enter → navigate → re-render) we need a mutable session object that owns the current Page plus per-session UI state and can SWAP its Page on navigation.

This task introduces that object PURELY ADDITIVELY. Do NOT change `Page` or any existing function signature. Do NOT touch main.rs (the interactive loop that consumes this lands in a later task). Everything stays inside `src/engine/`.

## Spec (record `spec: S-101` in the commit body; SPEC.md lives in the meta repo, latest is S-100 — use S-101)
Add a new public struct in `src/engine/mod.rs`:

```rust
/// A mutable browsing session that owns the current page plus interactive UI state.
/// spec: S-101
pub struct BrowsingContext {
    pub page: Page,
    /// Currently focused element (e.g. a text <input>), if any.
    pub focus_node: Option<NodeId>,
    /// Caret offset (in chars) within the focused input's value.
    pub caret_index: usize,
    /// Vertical scroll offset in CSS px.
    pub scroll_y: f32,
    /// Total laid-out content height in CSS px (for clamping scroll).
    pub content_height: f32,
}
```

Required methods (all on `impl BrowsingContext`):
1. `pub fn new(page: Page) -> Self` — wrap a freshly-rendered Page. Initialize `focus_node: None`, `caret_index: 0`, `scroll_y: 0.0`, and `content_height` from the page's layout box height (use the same height accessor the layout box already exposes; if none is obvious, read `page.layout`'s outer/border-box height field the way existing engine code reads layout geometry).
2. `pub fn navigate(&mut self, page: Page)` — REPLACE the current page with `page` and RESET session state on navigation: `focus_node = None`, `caret_index = 0`, `scroll_y = 0.0`, and recompute `content_height` from the new page's layout (same as `new`). This is the core "swap Page on navigation" primitive.
3. `pub fn set_focus(&mut self, node: Option<NodeId>)` — set `focus_node`; reset `caret_index` to `0` whenever focus changes to a different node (or to None).
4. `pub fn max_scroll(&self, viewport_height: f32) -> f32` — `(self.content_height - viewport_height).max(0.0)`.
5. `pub fn scroll_by(&mut self, dy: f32, viewport_height: f32)` — adjust `scroll_y` by `dy` and clamp into `0.0 ..= self.max_scroll(viewport_height)`.

Keep it minimal and correct. Do NOT add form-state fields beyond the above (FormState clearing can be wired when FormState is threaded in a later task — leave a single `// TODO(spec): clear FormState on navigate once FormState is owned here` line inside `navigate`).

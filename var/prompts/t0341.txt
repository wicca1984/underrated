## Task (t0341, milestone MS-NewTargets / News+Wiki images): implement CSS `object-fit` for `<img>` replaced elements.

### Background (verified by the orchestrator — trust these facts)

  1. `src/paint/mod.rs`: the `DisplayItem::Image { rect, src, base_url, decoded }` enum variant is DEFINED

     `<img>` element is handled (search for `name == "img"`, ~line 1265, the `dom.get_image(src)` /
     pre-decoded push at ~line 1287). At that construction site the node's computed `style` is available
     (the function holds a `styles: &HashMap<NodeId, ComputedStyle>` and the current `node_id`/`style`;
     mirror how other code reads `style.get("...")` e.g. `style.get("border-color")`).
  2. `src/raster/mod.rs`: the actual per-pixel nearest-neighbour scale-into-rect lives in the
     `DisplayItem::Image { .. }` match arm of the rasterizer (~line 163). The current loop maps each
     destination pixel to `fx = (x - rect.x)/rect_w`, `fy = (y - rect.y)/rect_h` clamped to [0,1], then

#### 2. Apply the fit math in the rasterizer (`src/raster/mod.rs`)
Replace the destination→source mapping in the `DisplayItem::Image` arm so it respects `object_fit`.
Compute, with `img_w = decoded.width as f32`, `img_h = decoded.height as f32` (both > 0, already guarded):
- Determine a uniform scale `s` (except Fill which is anisotropic):
    Contain:   s = min(rect_w/img_w, rect_h/img_h)
    Cover:     s = max(rect_w/img_w, rect_h/img_h)
    None:      s = 1.0
    ScaleDown: s = min(1.0, min(rect_w/img_w, rect_h/img_h))
    Fill:      keep EXACTLY the current behaviour (no aspect preservation) — see regression note below.
- For the non-Fill modes: drawn size `dw = img_w*s`, `dh = img_h*s`; centre it in the rect:
    `draw_x0 = rect.origin.x + (rect_w - dw)/2.0`, `draw_y0 = rect.origin.y + (rect_h - dh)/2.0`.
  Then for each destination pixel (x,y) that you already iterate over (still CLIPPED to the rect and to
  canvas bounds exactly as now): compute the source sample as
    `src_fx = (x as f32 + 0.5 - draw_x0) / dw`  (and analogously src_fy with dh)
  If `src_fx` or `src_fy` is outside [0,1) → this pixel is OUTSIDE the image (letterbox for contain/
  scale-down) → DO NOT paint it (skip; leave background showing). Otherwise sample
    `src_x = ((src_fx * img_w).floor() as u32).min(decoded.width - 1)` (same for src_y) and blend as now.
  For Cover/None where the image overflows the rect, the existing rect-clip on the iteration range means
  overflowing parts are simply never visited → natural crop. Good.
- Keep the existing canvas-bounds clipping (`x_start/x_end/y_start/y_end`) and the `blend(...)` call
  unchanged; only the fx/fy→src mapping and the skip-when-outside logic change.

REGRESSION SAFETY (critical): `object_fit == Fill` MUST produce byte-identical output to today. The
cleanest way: keep the current `fx/fy` clamped-[0,1] mapping verbatim for the `Fill` branch, and only use
the new centered/scaled mapping for the other four. Do NOT alter the Fill path's arithmetic.

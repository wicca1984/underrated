## Background
Tables are laid out (`src/layout/table.rs`), but the legacy HTML presentational attribute `<table border="1">`
draws NO cell gridlines today (paint has no table border logic). Real pages (Wikipedia infoboxes etc.) rely on
this. CSS borders are already painted generically via `SolidRect`; we only need to add the presentational-hint
borders that the `border` attribute implies.

## Spec (keep it simple, v0 presentational hint)
When an element is a `<table>`, `<td>`, or `<th>` AND its nearest ancestor `<table>` (inclusive, for the table
element itself) carries a `border` attribute whose value is present and not `"0"` / empty, draw a 1px solid
gray gridline (`Color::Rgba(128, 128, 128, 255)`) around that box's rect (all four edges).
- Tables WITHOUT a `border` attribute, and elements not in a bordered table, get NO extra border.
- Do NOT try to honor the numeric border width value; always draw 1px (v0). Leave a
  `// TODO(spec): honor numeric border width / border-collapse` marker.

## Goal
Real sites (Google) return a different, JS-heavy variant when no User-Agent is sent. To stabilize the
no-JS HTML variant we receive, `send_request` in `src/net/mod.rs` must attach a `User-Agent` request
header on BOTH the GET and POST branches.

## What to implement (src/net/mod.rs only)
1. Add a module-level constant with a realistic desktop browser UA string, e.g.:
   ```
   /// User-Agent sent on all outgoing HTTP requests so servers return the standard
   /// (no-JS-required) HTML variant. spec: RFC 9110 §10.1.5
   const USER_AGENT: &str =
       "Mozilla/5.0 (X11; Linux x86_64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36";
   ```
2. In `send_request`, on the `HttpMethod::Get` branch, after `let mut req = ureq::get(&url_str);`,
   add: `req = req.header("User-Agent", USER_AGENT);` (before or after the existing Cookie header logic —
   keep it consistent with the existing `req = req.header(...)` style already used there).
3. On the `HttpMethod::Post` branch, after `let mut req = ureq::post(&url_str);`, likewise add
   `req = req.header("User-Agent", USER_AGENT);`.

Do NOT change any other behavior (cookies, content-type, redirect, gzip, response parsing all stay as-is).

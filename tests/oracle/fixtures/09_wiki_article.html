Rust (programming language)

Introduction

Rust is a multi-paradigm, high-performance, general-purpose programming language designed for safety and concurrency. It is syntactically similar to C++, but provides memory safety without using garbage collection. Read more at the Rust Homepage.

History

The language grew out of a personal project by Graydon Hoare at Mozilla in 2006. Mozilla began sponsoring the project in 2009 and announced it in 2010. The first stable release, Rust 1.0, was released on May 15, 2015.

Key Features

  • Memory safety guarantees
  • Zero-cost abstractions
  • Safe concurrency models
